## 1. 🏭 ThirdEye AI — QR-Based Remote Support Platform

[![Repository](https://img.shields.io/badge/GitHub-View_Repository-181717?style=for-the-badge&logo=github)](https://github.com/Karangulia1/ThirdEye-AI)

**Overview**

ThirdEye AI is a remote support platform designed to connect deployed company projects and industrial sites with their assigned support stakeholders. It uses QR codes to help clients report technical issues and communicate with the responsible support team.

**Key Features**

- 📱 QR-based site identification and issue reporting.
- 🎫 Ticket creation and tracking.
- 👥 Stakeholder assignment.
- 💬 Client-support conversations.
- 📊 Issue status management.
- 🔐 User authentication and registration approval.
- 🤖 Future AI-assisted issue summarization and urgency classification.

**Technology Stack**

`Python` `FastAPI` `MySQL` `HTML` `CSS` `JavaScript` `JWT`

**Project Focus:** Backend development, API integration, database management, authentication, and remote support workflows.
